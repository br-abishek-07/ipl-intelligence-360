# Optional offline official franchise logos

The dashboard first looks for locally supplied `CSK.png`, `MI.png`, `RCB.png`, `KKR.png`, `SRH.png`, `RR.png`, `DC.png`, `PBKS.png`, `GT.png`, `LSG.png` (also accepts `.webp`, `.jpg`, `.jpeg`, and `.svg`). These are not included because the official team marks are third-party intellectual property.

If you have the right to use them for your capstone or another approved use, place them in this folder. The dashboard will embed those files without needing an internet connection.

Otherwise the dashboard tries IPL-hosted official logo URLs online and falls back to the project-created decorative team monograms offline. The remote URLs were **not verified reachable** in this build environment. Attribution and URL details appear in `../official_logos_manifest.csv`.
