# IPL Intelligence 360° — Phase V2-F Sports Analyst & QA Report

## Scope

A new **Advanced Player Intelligence Lab** has been integrated into the same V2-E Streamlit capstone app, without deleting the league EDA, all ten team pages, Records & Legends, or the four portable retrospective model files.

### New analytical experience

The separate `Player Intelligence Lab` sidebar route and home/team navigation links offer:

1. **Player scouting controls** — Cricsheet-ID player selector, IPL season range, franchise represented, opponent, venue, match stage and batting-first/chasing role. All primary sections respect a shared player-match filter. A second innings-phase selector applies only to head-to-head matchup data and is labelled as such.
2. **16 descriptive KPI cards** — recorded appearances, actual batting/bowling innings, runs, average, strike rate, milestones, boundaries, wicket credits, economy, not-outs, awards, team wins and win rate.
3. **Season evolution** — area/line/bar charts for total runs, wickets, strike rate and economy, with numerator/denominator transparency.
4. **Opponent and venue study** — runs and bowling dismissals versus opponent and by ground, with per-sample warnings.
5. **Innings-phase DNA** — powerplay/middle/death splits for batter runs, strike rate, dot-ball rate, and bowler-credited wickets.
6. **Recent form and distribution** — rolling five **batting innings** (not five arbitrary matches), rolling bowling wickets and score-bin distributions.
7. **Actual batter–bowler matchups** — one derived record per match/pair/phase, with balls, runs, dots, boundaries and credited dismissals; 12-ball minimum for charts, raw below-threshold numbers still available.
8. **Player comparisons** — consistent context filters applied to both selected players, side-by-side KPI table, clustered batting/wicket bars, season trend lines.
9. **Evidence exports** — match-level CSV and a reproducible Jupyter notebook.

### Definitions / protections against misleading analytics

- IPL batting average is batter runs divided by *dismissals*, **not** appearances, innings, or deliveries.
- Strike rate is batter runs per 100 faced balls. Bowler economy is runs charged to the bowler per six legal deliveries.
- Bowler-credited wickets exclude run-outs and all other non-bowler dismissals. Player-of-the-Match awards use stable player IDs.
- `info.players` may include substitutes or Impact Players. 'Recorded participation' is not interchangeable with a confirmed starting XI.
- Career totals exclude all Super Overs. Player direct matchups use regulation deliveries only.
- Venue and opponent analyses are descriptive, not adjusted for era, pitch, opposition quality, or player selection effects.
- No player-performance **prediction** model was trained or claimed to exceed 70% in V2-F. The existing four historical checkpoint models remain separate and are not re-evaluated by this module.
- Official player photographs are not redistributed. Team logos retain the existing IPL-hosted URL and local-permissioned fallbacks.

### QA / execution

Run from the project root:

```powershell
py -m pip install -r requirements.txt
py -m pip install pytest nbclient nbformat  # only for QA/notebook reruns
py -m pytest tests -q
py -m streamlit run app.py
```

**All 96 automated tests passed** (79 prior + 17 new). The new tests check batting and bowling reconciliation, player IDs, scoped seasons, phase and matchups, disambiguation, sample counts, full-screen renderer reuse and a simulated seven-tab player-page render.

The executed `notebooks/V2F_Player_Intelligence_EDA.ipynb` contains 10 executed Python cells and 11 Markdown cells, without execution errors.

**Browser verification remains required on the user's Windows laptop.** This build environment has pandas and Plotly but does not have Streamlit installed, so a real browser-based interaction and responsive-layout assessment could not be completed here.
